# PROCEDIMIENTO
1. Preparación de los datos (eliminar filas y columnas).
2. Undersampling de forma aleatoria. Con esto terminaríamos con 50% benigno y 50% maligno.
3. Oversampling usando SMOTE. Hacemos oversampling de cada clase maligna para que sean equitativas a la mayor clase maligna.

Aproximadamente 10M de datos.
